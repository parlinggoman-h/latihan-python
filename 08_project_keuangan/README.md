# 💰 Aplikasi Keuangan CLI

Aplikasi pencatat keuangan (pemasukan & pengeluaran) berbasis Command Line Interface (CLI) yang dibuat dengan Python.

## ✨ Fitur

- ✅ Tambah pemasukan
- ✅ Tambah pengeluaran
- ✅ Lihat semua transaksi (tabel rapi)
- ✅ Lihat ringkasan (total pemasukan, pengeluaran, saldo)
- ✅ Hapus transaksi
- ✅ Format rupiah otomatis (Rp 5.000.000)
- ✅ Validasi input lengkap

## 🚀 Cara Menjalankan

1. Pastikan Python sudah terinstall
2. Buka terminal di folder ini
3. Jalankan:

```bash
py keuangan.py
```
