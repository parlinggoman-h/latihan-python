# 📝 To-Do List CLI

Aplikasi daftar tugas (to-do list) berbasis Command Line Interface (CLI) yang dibuat dengan Python.

## ✨ Fitur

- ✅ Lihat semua tugas
- ✅ Tambah tugas baru
- ✅ Tandai tugas sebagai selesai
- ✅ Hapus tugas
- ✅ Validasi input (kosong, bukan angka, di luar range)

## 🚀 Cara Menjalankan

1. Pastikan Python sudah terinstall
2. Buka terminal di folder ini
3. Jalankan:
```bash
py todo_list.py
```
